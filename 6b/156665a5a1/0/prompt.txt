다음과 같은 사항도 적용하고 싶어 어떤지 알려줘
1. github에(origin) 이슈를 올리면 웹훅을 통해 감지하고 세션에서 작업을 수행하고 싶어.
1.1 이 때 plan 모드로 주고받은 대화는 해당 이슈에 남기고 싶어. 혹은 해당 이슈에 코멘트를 달면 웹훅으로 세션에 전달하고 싶어.
2. 이 때 브랜치는 feature/#{issue_number}으로 수행하게 하고 싶어.
3. 각 브랜치에서 최초 커밋이 발생할 경우 push-pr이 되도록 하고 싶어.
4. 대화기록을 해당 PR에 코멘트로 전문을 남기고 싶어. 네가 작성한 내용은 여기엔 영문이지만 코멘트엔 한글로 남기고 싶어.
5. 네가 말한 내용은 클로드가 작성했다고 표시하고 싶어.
6. PR이 merge될 경우, 웹훅으로 세션에서도 merge시키고 싶어.
